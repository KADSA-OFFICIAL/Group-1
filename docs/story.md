## 1. 핵심 테마

**"알지 말았어야 할 것"**

이설은 국어책을 가지러 밤에 학교에 몰래 들어왔을 뿐이다. 들키면 야간 무단 침입으로 벌점, 최악엔 정학. 수위 아저씨한테 안 걸리고 빠져나가면 그만이었다.

문제는 — 숨어 있다 보니 이상한 게 보이기 시작했다는 것이다. 사라진 학생의 학생증, 누군가 수거해놓은 소지품 봉투, 벽에 적힌 의미 모를 날짜들. 퍼즐 조각이 하나씩 맞춰지면서 이설은 깨닫는다 — 이 학교에서 사라진 학생들, 그리고 매일 밤 학교를 순찰하는 수위 아저씨 사이에 연결 고리가 있다는 것을.

처음엔 그냥 나가면 됐다. 지금은 나가야만 한다. 이걸 알아버렸으니까.

플레이어의 목표는 단순하다: 수위에게 들키지 않고 1층 현관까지 내려가서 학교를 탈출하는 것. 하지만 층을 내려갈수록 단서가 눈에 띄고, 무시하고 지나칠지 확인하러 갈지는 플레이어의 선택이다. 많이 알수록 위험하고, 많이 알수록 엔딩이 달라진다.

## 2. 주요 인물

### 이설 (주인공)

* 불암고 2학년 3반.
* 조용하고 존재감이 옅은 편. 혼자 다니는 일이 많다.
* 친구가 많지 않지만, 본인은 크게 신경 쓰지 않는 척한다.
* 관찰력이 좋다. 남들이 지나치는 것을 본다.
* 엄마와 단둘이 산다.

### 박종태 (수위)

* 62세. 불암고 개교 이래 32년 근무.
* 10년 전까지는 학생들에게 간식을 나눠주던 다정한 아저씨였다.
* 딸 시우의 죽음 이후 말수가 줄었고, 밤에만 학교를 돌아다닌다.
* 낮에는 평범하지만, 밤이 되면 눈빛이 달라진다.
* 자신이 하는 일을 "심판"이라 부른다. 죄책감은 있지만 멈추지 못한다.

### 박시우 (수위의 딸, 고인)

* 10년 전 불암고 1학년.
* 내성적이고 그림을 좋아했다. 미술실을 좋아했다.
* 같은 반 아이들에게 오랫동안 괴롭힘을 당했다.
* 담임에게 호소했으나 "학생들끼리 잘 해결하라"는 말만 돌아왔다.
* 결국 학교 옥상에서 추락하여 사망. 학교는 사고사로 마무리.

### 실종 학생

| # | 이름 | 학년/반 | 실종 시기 | 종태가 판단한 "죄" | 실제 사정 | 흔적 위치 |
|---|---|---|---|---|---|---|
| 1 | 강유진 | 3학년 1반 | 1년 전 | 후배를 상습 폭행 | 실제로 폭력적이었음 | 2층 체육관 |
| 2 | 조민혁 | 2학년 2반 | 3개월 전 | 수업 중 교사를 모욕하고 기물 파손 | 가정 문제로 폭발한 것이었음 | 4층 과학 실험실 |
| 3 | 송하람 | 1학년 3반 | 3주 전 | 보건실에서 약한 학생을 때림 | 종태의 오해. 실은 아픈 친구를 부축하던 중 | 5층(프롤로그) |

> 원문 표에는 위 3명만 채워져 있다(나머지 행은 비어 있음). 다만 8장 플래그 목록과
> 에픽 #137에는 **백승호(2학년 4반, 2층 교무실)** 와 **임나연(1학년 6반, 3층 방송실)** 이
> 더 있어 실종 학생은 총 5명이다.

→ 핵심: 실종 학생 중 일부는 실제로 문제가 있었고, 일부는 종태의 오해로 희생되었다. 플레이어는 이 구별을 스스로 판단해야 한다.

## 4. 본편 — 층별 내러티브

게임 플레이 중 interactable 오브젝트를 통해 전달되는 환경 서사. 플레이어는 단서를 무시하고 계단만 찾아 빠르게 탈출할 수도 있고, 위험을 감수하고 방을 조사해서 진실을 밝혀낼 수도 있다.

### 4-1. 4층 (시작 층)

프롤로그에서 미술실·옆 교실은 이미 방문. 4층의 나머지 방에 추가 단서가 있다.

#### 다산실 (계단 열쇠 + 송하람 관련 심화)

```
[내레이션] 서랍에 열쇠. [4층 계단 열쇠 획득]
[내레이션] 교탁 아래 접힌 메모.
[메모]    "하람아, 은수 때린 거 수위 아저씨가 봤다더라. 조심해. — 재영"
[내레이션] 메모 뒷면에 다른 필체.
[메모]    "나 안 때렸어. 쓰러지길래 잡은 건데. 아무도 안 믿어줘."
[이설]    프롤로그에서 찾은 학생증… 송하람. 때린 게 아니라 도운 거라고?
```

#### 상담실 (선택 탐색)

```
[내레이션] 상담 기록 캐비닛. 잠겨 있지만 한 서랍만 반쯤 열려 있다.
           폴더 하나가 삐져나와 있다 — "박시우."
[상담 기록]
          "박시우 (1학년 2반)
          상담 회차: 7회
          주호소: 또래 관계 어려움, 수면 문제

          4회차: 같은 반 일부 학생에 의한 지속적 괴롭힘 호소.
          담임 연계 요청 → 담임 회신: '과장된 측면이 있음. 관찰 중.'

          7회차: 내담자 상태 악화. 등교 거부 시작.
          학부모(부, 박종태) 면담 → 학교 차원 조치 요청.
          학교 측 회신: '가해 학생 특정 어려움. 추가 상담 권고.'

          — 이후 기록 없음 —"

[이설]    박시우… 수위 아저씨가 미술실에서 말한 이름이다.
          수위 아저씨 딸이었어?
          일곱 번이나 상담을 했는데 학교가 아무것도 안 한 거야?
```

이후 상담실 구석에 있는 인쇄실 열쇠를 찾음.

#### 인쇄실 (선택 탐색)

```
[내레이션] 인쇄기 옆에 종이 뭉치가 있다.
           한 장만 인쇄가 되어 있다.
[인쇄물]  "불암고등학교 학생 사망 사고 대응 매뉴얼 (비공개)

          1. 언론 접촉 차단.
          2. '교내 안전사고'로 통일.
          3. 유족 합의 우선.
          4. 재발 방지 대책은 합의 종결 후 검토."

[이설]    …매뉴얼이 있다고?
          대응 매뉴얼이 있을 만큼 일이 있었다는 건데.
```

옆에 있는 잉크를 찾음. (이걸로 수위 아저씨의 눈을 잠시 멀게 할 수 있을 듯 하다)

### 4-2. 4층

#### 과학 실험실 (계단 열쇠 + 조민혁 흔적)

```
[내레이션] 실험대 서랍에 열쇠.
           [4층 계단 열쇠 획득]
[내레이션] 실험대 위에 깨진 비커 조각과 의자가 넘어져 있다.
           며칠은 된 것 같다.
[내레이션] 바닥에 찢어진 가정통신문.
```

## 5. 수위 조우 이벤트

수위는 플레이어를 적극적으로 쫓지 않는다. 정해진 순찰 루트를 돌며 가끔 각 방을 확인한다. 플레이어는 발소리와 열쇠 소리를 단서로 수위의 위치를 파악하고, 숨거나 우회해야 한다.

### 수위가 근처에 있을 때 (소리로 존재감 전달)

```
[내레이션] — 찰랑. 열쇠꾸러미 소리. 가까워지고 있다.
[내레이션] 발소리. 복도 저쪽에서. 느릿느릿.
[내레이션] 문이 열리는 소리. 수위가 방을 확인하고 있다.
```

### 수위 독백 (순찰 중 혼잣말, 간접적으로 들림)

```
[수위]    (중얼) …오늘도 아무도 없지.
[수위]    (중얼) 시우야, 아빠 순찰 중이야.
[수위]    (중얼) 이 학교는 내가 지킨다…
[수위]    (중얼) 다 끝나면 올라갈게.
```

### 주인공의 시야 안에 들 시

주인공의 시야 안에 수위 아저씨가 보이면 플레이어를 따라온다. 속도는 때에 따라 다르다. 빠를 수도 있고 느릴 수도 있다.

### 발각 시 (`CONTACT_DISTANCE` 이내 → 게임 오버)

```
[수위]    …누구야?
[내레이션] 손전등 불빛이 이설의 얼굴을 비춘다.
[수위]    학생이네. 이 시간에 뭐 하는 거야.
[이설]    ……
[수위]    나와. 같이 수위실로 가자.

[캡션]    — 발각 —
[내레이션] 이설은 수위실에서 아침까지 붙잡혀 있었다.
           다음 날, 야간 무단 침입으로 교무실에 호출되었다.
           이설이 학교에서 본 것들은
           아무에게도 말할 기회가 없었다.
```

→ 발각 = 게임 오버 화면 → 타이틀로 복귀. 사망이 아니라 "잡힘".

## 7. 분기 요약 플로우

```
프롤로그
  │

                          │
                     수위 등장, 캐비넷에 숨음

                          │

                          │
                     연결문 → next_room
                     (소지품 봉투 + 벽의 날짜 발견)
                          │
                     수위 복귀 → 창문으로 탈출
                          │
                        @game

  본편 (5층→1층 스텔스 탈출)
  │
  ├─ 수위에게 발각 시: 게임 오버 → 타이틀
  │
  ├─ 탈출 시점에서 분기:
  │
  │   현관 열쇠만, 신고 안 함 ──────→ 기본 엔딩 "방과 후"
  │   편지 or 공책 발견 + 신고 선택 → 신고 엔딩 "어른들의 일"
  │   5명 흔적 + 상담 기록 + 공책
  │   + 시우 그림 재조사 ──────────→ 숨은 엔딩 "쉬는 시간"
  │
  └─ (미래 확장) 전투/대결 루트
```

> 구현에서는 엔딩 분기를 넣지 않았다 — "방과 후" 1종만 있고 현관에서 판정하지 않는다(머리말 참조).

## 8. 구현 참고

### 프롤로그 변경

`intro.gd`의 `SCRIPT_NODES` 교체. 신규 장면 키: `back_gate`, `art_room`, `cabinet`, `next_room`. 프롤로그 완료 시 `set_flag("found_songharam")` 자동 설정 (캐비넷에서 학생증 발견).

### 환경 서사

각 층 씬에 Interactable 노드 추가. 단서 발견 시 `set_flag()`로 기록. 수위 공책은 여러 페이지로 나눠 조사할 때마다 다음 내용을 보여주는 방식 권장 (한 번에 다 보여주면 긴장감이 떨어짐).

### 엔딩 분기

`exit_door.gd` 수정:

* 편지 or 공책 플래그 보유 시: 탈출 전 선택지 UI 표시 (신고 여부)
* 5명 흔적 + 상담 기록 + 공책 + 시우 그림 플래그 전부 보유 시: 숨은 엔딩 자동 진입
* 그 외: 기본 엔딩

### 수위 행동

`janitor.gd`를 순찰 기반으로 변경.

* 추격 모드 대신 순찰 루트를 따라 이동하며 방을 하나씩 확인.
* 플레이어와 같은 층일 때 발소리·열쇠 소리를 `game_state.request_notice()`로 전달.
* 혼잣말은 수위가 근처에 있을 때만 간헐적으로 출력.
* `CONTACT_DISTANCE` 이내 접근 시 발각 → 게임 오버(타이틀 복귀).
